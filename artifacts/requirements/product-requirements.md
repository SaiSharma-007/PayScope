# Salary Management Product Requirements

## Goal

An HR Manager needs one place to replace spreadsheet-based salary tracking and answer questions about how the organization pays 10,000 employees across multiple countries.

## Scope

- The deployed React app opens on a public landing page that introduces the demo. One HR Manager account signs in to access employee and salary data. The demo uses 10,000 fictional employees generated by a repeatable seed command.
- HR can search the employee directory by name or ID, combine country, department, and job title filters, and page through results. HR can view, enter, or replace the current annual gross base salary and its recorded currency for an existing employee.
- HR can apply the same filters in analytics and optionally group by one dimension. Reports summarize the full matching set of recorded salaries and show minimum, median, maximum, average, and salaried headcount for each group and currency. A range chart and exact-value table let HR compare groups within one selected currency.
- **Ask about pay** uses a Microsoft Agent Framework orchestrator to coordinate the Pay Analyst, reporting tools, and Answer Writer. HR sees live stages, handoffs, tool calls, and streamed answer text, with an **Open report** action. Chats are saved, independent conversations can run concurrently, and HR can stop or reconnect to a selected run.
- Async FastAPI serves React, the APIs, and the agent event stream. PostgreSQL stores source data and run events, and Redis caches analytics. Reports reflect committed salary edits on the next request and fall back to PostgreSQL during a Redis outage.

## Deliberate exclusions

Monthly pay, bonuses, salary history, payroll, and bulk editing are outside scope so the app stays focused on current base pay. Reports use recorded currencies and the demo uses one HR role. The agent answers group-level questions, and individual salary changes belong to the salary form.

## Release checks

- A reviewer can update a salary, verify the report, and ask a pay question while watching tool execution and the answer stream. Stop and reconnect preserve a clear run outcome.
- Deterministic tests cover salary rules, report calculations, verified agent claims, and streaming recovery. A fixed question set evaluates tool selection and answers. Performance notes cover search, reports, and first agent output.
- The Git history shows incremental work, starting with requirements before application code. The repository includes design notes, representative AI prompts and verification, reviewer access instructions, and links to the deployed app and video demo.
